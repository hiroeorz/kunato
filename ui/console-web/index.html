Traffic and rejections per minute

UTC interval starts. Bar height is the per-minute rate over complete minutes, so retained 1-minute and 1-hour intervals are comparable. The reporting-period switch above selects the 7-day, 14-day, or 28-day view; the display interval is 3, 6, or 12 hours. The time axis always spans the selected range, so bars appear only where history is retained. Hover or use the arrow keys for totals, storage grain, and coverage.

Traffic and rejections by country

The same UTC intervals and per-minute rates as the traffic chart, split by the embedded DB-IP country lookup. The left bar is requests and the right bar is rejected requests. Countries outside the top eight are grouped as OTHER; intervals without country detail are left empty.

Blocked requests by country

All WAF-rejected requests in the fetched range, mapped by the resolved source country. Darker colour means more blocked requests; the scale is logarithmic so a single large source does not hide smaller countries. Grey means no country detail, pale means zero blocked requests.
