# Requests that Kunato must stop before they reach the upstream.
#
# One request per line:
#   METHOD TARGET [key=value ...]
#   - `ua`     sets the User-Agent header
#   - `body`   sets the request body
#   - `header` sets an arbitrary header using `Name: value`
#   - any other key becomes a request header
#   - values with spaces or quotes are quoted with "..."; use \" for a literal
#     quote and \\ for a backslash inside a quoted value
# Blank lines and lines starting with `#` are ignored.
#
# These requests exercise the rules in rules.example.yaml. Run Kunato with a
# configuration that does not list this client in `trusted-sources`.
